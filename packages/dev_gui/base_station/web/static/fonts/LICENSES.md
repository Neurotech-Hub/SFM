# Font licenses

These three font files are served by the gateway itself so the Pi never contacts
a font service. All are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows bundling and redistribution.

| File | Family | Weights | Source |
|---|---|---|---|
| `inter.woff2` | Inter (Latin subset) | 400-600 | https://github.com/rsms/inter |
| `jetbrains-mono.woff2` | JetBrains Mono (Latin subset) | 400-500 | https://github.com/JetBrains/JetBrainsMono |
| `space-grotesk.woff2` | Space Grotesk (Latin subset) | 500-700 | https://github.com/floriankarsten/space-grotesk |

The files are the variable-font Latin subsets published through Google Fonts.
